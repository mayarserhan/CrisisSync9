\# CrisisSync — Group 9



\*\*CrisisSync\*\* is an emergency and crisis management system designed to coordinate incident response, atomic resource-package reservations, real-time task execution tracking, and SLA (Service Level Agreement) performance reporting.



This repository contains the software engineering artifacts, models, requirements documentation, and version history for the CrisisSync course project.

\## Repository Structure



\- `README.md` — Project overview and repository index.

\- `REQUIREMENTS.md` — Assignment 1 functional requirements (FR), measurable non-functional requirements (NFR), Requirements Traceability Matrix (RTM), and BDD acceptance tests (`Given-When-Then`).

\- `G9\_Assignment1.vpp` — Visual Paradigm (v18.1) Use Case model, including system boundary, actors, relationships (`include` / `extend`), and full Use Case specifications.

\- Engineering text / PlantUML source files — Text-based diagram sources tracked for version control.



\## Assignment 1 Scope



1\. \*\*Use Case Modeling (Visual Paradigm 18.1):\*\* Complete operational modeling of the CrisisSync system, covering normal flows, error handling, and failure recovery scenarios.

2\. \*\*Requirements Engineering \& Acceptance Testing (`REQUIREMENTS.md`):\*\*

&#x20;  - Resource package reservation (manual and automatic allocation) and task completion reporting.

&#x20;  - Monthly scheduled and on-demand SLA report generation.
